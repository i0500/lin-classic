# Classic Supporter (린클래식)

리니지 클래식 **사냥 서포터** — 화면 인식으로 HP·MP 상황별 스킬을 자동 사용하는 보조 도구.

> ⚠️ 캐릭터를 대신 움직이는 ‘오토’가 아닙니다. 이동·전투는 직접 하시고, 그 위의 상황 대응(HP/MP 스킬, PK·물약, 사망/석화 인식)만 거듭니다.

## ⬇️ 다운로드
[**Releases**](https://github.com/i0500/lin-classic/releases) 에서 최신 zip 다운로드 → 압축 비밀번호 **`1111`** → `ClassicSupporter.exe` 실행 (설치 불필요).

## ✨ 주요 기능
- **첫 실행 단계별 튜토리얼** — 설정을 손잡고 안내
- **실시간 모니터링** — 몹·아이템·내 캐릭터 구분, 이동/전투 자동 구분
- **HP·MP 인식** — 자동 찾기 / ROI 박스 조정 / OCR 텍스트 모드
- **상황별 스킬 슬롯** — HP·MP 구간, 연사·쿨타임, 단축창 전환
- **PK · 물약 대응**, **사망 · 석화 인식**
- **PostMessage / 아두이노 HID** 입력, 알람 · 텔레그램, 테마

## 🖥️ 권장 환경
Windows 10 / 11 · 게임 해상도 1280×720 이상 · 디스플레이 배율 100%

## 🔄 업데이트
정식 빌드는 실행 시 이 저장소의 릴리즈를 확인해 새 버전을 알려 줍니다.
